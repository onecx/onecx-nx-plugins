== Generate a UI App

The Angular generator supports three flavors: *angular*, *ngrx* and *standalone-ngrx* (with the OneCX standalone development shell). +
It is **recommended to use the NgRx** flavor, because it leads to better structured projects and the state management is already in place. +
The creation of a new workspace takes a while, as the generator sets up a complete Angular application with all necessary dependencies and configurations.

[NOTE]
====
Generated UI Apps build and serve with Rspack (`@nx/rspack`) instead of Webpack, configured through the generated `rspack.config.js`.
This describes the current generator implementation; previously published versions can still scaffold Webpack.
For local branch validation, publish the matching launcher, generator and utility packages to a local registry as described in the repository README, then use the same version and registry when creating the app.
An unversioned `npx` command selects the public `latest` tag, not your local checkout.
====

.Generate the UI App with following commands
[source,bash]
----
npx <namespace>/create-workspace <flavor> <product> [--appPrefix=<prefix>]
cd <product>
npm install

The generator creates a new directory with the specified product name and sets up the OneCX UI App according to the chosen flavor. +
Use a new directory to validate scaffolding. Installing or copying an updated generator does not migrate an existing application's build configuration. +
Please note that the product name from your command is used as base of some essential application parts as following:

=== Key Naming Conventions
`appPrefix` is optional and defaults to the empty string.
Use `--appPrefix=onecx` to retain the legacy application prefix, `--appPrefix=acme`
for a custom prefix, or `--appPrefix=""` for an explicitly empty prefix.
The separated forms `--appPrefix acme` and `--appPrefix ""` also work.
Prefixes are lowercase kebab-case with no trailing separator.
For product `orders`, omitted/empty yields `orders-ui` and `orders-bff`;
`onecx` yields `onecx-orders-ui` and `onecx-orders-bff`;
`acme` yields `acme-orders-ui` and `acme-orders-bff`.

The prefix is applied once to the product slug. It does not change the workspace
directory, product-based routes or OneCX framework dependencies.
For an example with `--appPrefix=acme` and product `orders`:

* `acme-orders-ui` +
  Project name +
  Helm chart name for deployment and microservice registration in OneCX
* `acmeOrdersUi` +
  Identifier-safe federation remote name (also used in operator metadata)
* `AcmeOrdersUiModule` / `./AcmeOrdersUiModule` +
  Module class and federation exposed identifier, imported from `acme-orders-ui.remote.module.ts`
* `acme-orders-ui-component` +
  Tag name for integration the web component into the DOM
* `onecx-apps/acme-orders-ui` +
  Repository name for docker image repository
* `/mfe/<product>/` +
  Base path for the microfrontend application, used within OneCX for integration purposes
* `dist/acme-orders-ui/` +
  Build output and Docker COPY source
* `http://acme-orders-bff:8080/` +
  Default Docker, development proxy and OpenAPI BFF destination

The same option works directly on the generators, for example:

[source,bash]
----
nx g @onecx/angular-generator:ngrx orders --appPrefix=acme --non-interactive
----

Next step may xref:./create-feature.adoc[create a feature module].

[NOTE]
====
The generated app contains the dependency for the OneCX Angular Generator (`@onecx/angular-generator`). +
This allows you to easily add new features, components, and services within your app's user interface using the OneCX Angular Generator functions. +
(This package was named `@onecx/nx-plugin` prior to version 9.)

== Example

The following commands create a new workspace directory named "bookstore" with the necessary structure and configurations for a OneCX UI App using {ngrx_link}. This can take a while, as the generator sets up a complete {angular_link} application with all necessary dependencies and configurations.

.Create a UI App named "bookstore" (product) with NgRx support
[source,bash]
----
npx @onecx/create-workspace ngrx bookstore
cd bookstore
npm install
----
